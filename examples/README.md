# Examples

- [`professional-network/`](professional-network) — TypeScript, from a one-sentence idea to a tested module, two edge-case requests and a planted regression.
- [`medical-appointments/`](medical-appointments) — Java, from a one-sentence idea to a tested module, with a human answering the product bets and a concurrency edge case.
- [`meal-delivery-cart/`](meal-delivery-cart) — Kotlin, a money-heavy domain: exact rounding, amounts at the limits of the range and a pure function, with a human answering the money rules.

The three examples were built with the roles and skills as of the commit titled "Test cases name a source, and the bridge counts the ones that do not". The Product Owner's INVEST check, added to `main` since, is not part of it.

# Examples

- [`professional-network/`](professional-network) — TypeScript, from a one-sentence idea to a tested module, two edge-case requests and a planted regression.
- [`medical-appointments/`](medical-appointments) — Java, from a one-sentence idea to a tested module, with a human answering the product bets and a concurrency edge case.
- [`meal-delivery-cart/`](meal-delivery-cart) — Kotlin, a money-heavy domain: exact rounding, amounts at the limits of the range and a pure function, with a human answering the money rules.
- [`copro-parking/`](copro-parking) — Python, a register of lots and parking spaces in a co-ownership: a clean-architecture core with a JSON store, a manager-only permission check, a human answering every product question and one review-driven fix iteration. The first run watched live on the office floor.

The first three examples were built with the roles and skills as of the commit titled "Test cases name a source, and the bridge counts the ones that do not". The Product Owner's INVEST check, added to `main` since, is not part of it. `copro-parking` was built later, with the roles as of the commit titled "Add TL;DR and diagrams to generated docs; durations, document reader and resting agents on the floor".

## Slices

- **Slice 1, walking skeleton (Now):** sign up, create a basic profile, send and accept a connection, publish a post, read a connection's post. Includes consent at sign-up and account deletion (EU baseline).
- **Slice 2, complete the core (Now):** edit and remove (profile, posts, connections), profile visibility choices, data export.
- **Slice 3, segment reach and safety (Next):** search for colleagues, block, report.
